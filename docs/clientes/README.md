# `docs/clientes/` — Clientes

Documentação sobre quem usa (ou deveria usar) o produto: ICP, personas, segmentação, pesquisa
qualitativa e quantitativa, feedback e síntese de entrevistas.

## O que vai aqui

- ICP (Ideal Customer Profile) e critérios de qualificação.
- Personas relevantes.
- Sínteses de pesquisa (entrevistas, pesquisas, dados de uso agregados).
- Feedback recorrente de clientes, classificado por tema.

## Regras

- Toda persona/ICP deve indicar se está `Confirmado`, `Inferido` ou `Hipótese` (ver
  `docs/corpus/README.md`) até haver evidência suficiente para promovê-la a `Confirmado`.
- Pesquisa bruta (transcrição de entrevista, printscreen, etc.) fica em `docs/corpus/`; aqui fica
  a síntese já analisada, com origem citada.
- Usar os templates `templates/icp.md` e `templates/pesquisa-de-problema.md` como ponto de
  partida.

# `docs/mercado/` — Mercado

Documentação sobre o ambiente externo ao produto: concorrência, posicionamento, tamanho de
mercado, tendências e benchmarks.

## O que vai aqui

- Análise de concorrentes e battlecards.
- Posicionamento e diferenciação.
- Tamanho de mercado e segmentação (quando houver dado confiável — ver regra de classificação).
- Benchmarks de mercado relevantes para priorização.

## Regras

- Toda estimativa de mercado sem fonte primária confiável deve ser marcada como `Hipótese` ou
  `Inferido` (ver `docs/corpus/README.md`) — nunca apresentada como `Confirmado` sem evidência.
- Não inventar dados de mercado, concorrentes ou benchmarks que não constem no corpus ou em
  fonte externa citável.

# `docs/operacao/` — Operação

Documentação de operação do próprio sistema: estado de trabalho, aprendizados/gotchas, e o
espelhamento operacional no Linear.

## Conteúdo

- `estado.md` — memória de trabalho volátil (onde paramos, próximo passo, bloqueios). Ver skill
  `/handoff`.
- `aprendizados.md` — staging volátil de aprendizados e gotchas; o que estabiliza é promovido
  para ADR, glossário ou `CLAUDE.md` e removido daqui.
- `linear.md` — hierarquia, estados, rótulos e convenções de uso do Linear como espelho
  operacional deste repositório.

## Regra

`docs/operacao/` documenta *como operamos*, não *o que decidimos* (isso vai em
`docs/decisoes/`) nem *o que construímos* (isso vai em `docs/produto/` e `specs/`).
